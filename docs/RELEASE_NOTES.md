# Glimpse v0.62.1

**新增**
- 悬浮窗磨砂可调：设置 → 主题 → 界面，开关 + 强度（4–32）
- 底栏上方 18px 磨砂过渡区，内容滚到此处先被模糊，不再清晰压到底栏下

**优化**
- 顶栏搜索框与切换按钮改用卡片色 + 细边框，与内容区材质统一
- 设置「主题」分区重排：外观 → 配色 → 圆角 → 节点外观 → 界面 → 底栏 → 背景 → 流量图
- 切页动画放慢至 460ms，缩放幅度收到 4%，过渡更柔和
- 按压反馈加强：代理组 0.89、供应商 0.94、连接卡 0.95、设置行 0.96
- 悬浮窗打开 / 关闭时长分离：代理组 320/260ms，供应商 320/180ms
- 悬浮窗收回时的圆角改为跟随卡片圆角，不再变成椭圆

**修复**
- 底栏开启毛玻璃后整屏模糊（模糊层未裁剪）
- 界面磨砂把背景糊掉而不是作用于界面（已移除该实现）

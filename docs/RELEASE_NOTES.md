# Glimpse v0.58.1

首个公开版本。

## 功能

- **仪表盘**：实时上下行速度（点阵频谱 / 块状 / 折线）、网络信息（可打码隐藏 IP）、出站模式切换、延时测试、连接统计、内核内存占用；卡片可排序与隐藏
- **代理**：分组卡片（LOGO / 可用节点数 / 当前节点 / 延时）、点击延时测速、节点悬浮窗、多级嵌套分组、机场订阅页（用量条 + 可用比例条）、分组与节点独立排序、按机场分组、自动组手动锁定标记
- **连接**：实时列表（按建立时间倒序）、分组与字段自定义、可断开
- **规则**：规则列表（序号 / 命中流量 / 目标策略）、本地停用、规则集供应商
- **日志**：实时流、级别过滤、暂停、搜索、清空
- **设置**：多后台管理与切换、测速地址配置、6 套主题配色 + 色盘自定义、字体与字号、圆角/透明度/背景、中英文切换、内核诊断与维护操作

## 安装

1. 下载 `Glimpse-v0.58.1-arm64-v8a.apk`
2. 确保 mihomo 已开启外部控制（`external-controller: 0.0.0.0:9090`）
3. 安装后进入「设置 → 连接 → 添加后台」，填入地址与密钥

## 说明

- 本 App 仅为控制台，不包含内核、不提供 TUN 与订阅
- 仅支持 Android 24+
- 签名使用 debug key，仅供个人使用

# Glimpse v0.60.1

**新增**
- 规则显示目标代理组的配置 logo
- 连接详情新增「原始数据」页（JSON 可复制）
- 连接支持「按时间」分组
- 节点卡字号 / 间距 / 留白可在设置里调节

**优化**
- 连接卡重排：左列类型/域名/链路/规则，右侧流量与时间，连接时刻在右下角
- 连接按时间倒序，新连接永远在最前
- 切页加入弹性回弹，和底栏手感一致
- 分组延时角标放大

**修复**
- 代理页偶发空白 / 红字
- 点击分组延时无反应（现在会转圈并逐个兜底测速）
- 手动锁不消失
- 选中节点后延时不同步
- 关掉「连接时长」后仍显示

安装：下载 arm64 APK，在「设置 → 连接」填入 mihomo 控制器地址与密钥。

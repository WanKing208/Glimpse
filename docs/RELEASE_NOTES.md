# Glimpse v0.67.2

**连接**
- 连接类型显示完整协议：`HTTPS · TCP`
- 连接时间改为相对格式（`12 秒前` / `3 分钟前`），不再显示绝对时刻
- 新增「按时间」分组，新连接排最前
- 详情弹窗改为不透明并支持查看原始 JSON

**代理**
- 长按代理组直接测速，带震动反馈
- 修复机场节点在悬浮窗 / 单节点测速时全部超时：优先走整组、整机场接口
- 分组延时字号加大加粗，更醒目
- 新增 IPv6 探测开关（设置 → 代理设置），测速时探测节点是否支持 IPv6，结果持久化，标记合并进协议行：`vless·xudp·ipv6`
- 供应商与代理组节点布局统一，延时固定在右下角

**仪表盘**
- 连接统计改为心率走势图，连接数移到右上角
- 流量图新增 4 种样式：平滑曲线、渐变面积、阶梯线、心电尖峰（默认仍为点阵）
- 修复删不掉的空白模块

**性能**
- 页面改为按需构建，未访问的页面不再后台运行
- 底栏模糊从 2 层合并为 1 层，并移除多余阴影

**视觉**
- 顶栏搜索与切换按钮统一为卡片色 + 细边框
- 切页动画调整为 560ms 弹性回弹
- 所有按压反馈加强
- 选项弹窗统一为居中悬浮样式

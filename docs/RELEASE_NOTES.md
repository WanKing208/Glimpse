# Glimpse v0.59.2

**新增**
- 供应商可用节点分段条：绿(<300ms) → 黄(300–699) → 红(≥700) → 灰(不可用)，按占比显示
- 分组悬浮窗右上角显示 logo
- 悬浮窗高度随节点数量自适应

**优化**
- 移除重复的测速按钮，测速统一走延时角标
- 节点卡边框更淡，选中改为无边框 + 深色整块
- 延时字号放大，节点卡底色统一加深

**修复**
- 分段条不显色
- 代理页偶发空白
- 实时流量 / 内存长时间不刷新

安装：下载 arm64 APK，在「设置 → 连接」填入 mihomo 控制器地址与密钥。仅支持 Android 24+。

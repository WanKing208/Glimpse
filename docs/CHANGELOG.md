# 更新日志

## v0.59.2

**新增**
- 供应商可用节点分段条：绿(<300ms) → 黄(300–699) → 红(≥700) → 灰(不可用)，按节点占比填充，灰色固定在最后
- 分组悬浮窗右上角显示分组 logo（34dp）
- 悬浮窗高度随节点数量自适应（18%–52%）

**优化**
- 移除悬浮窗重复的测速按钮，测速入口统一为延时角标
- 节点卡边框更淡（0.5px / 22%）
- 代理组与供应商节点卡统一下沉底色，层级更清晰
- 选中节点改为「无边框 + 深色整块」
- 延时字号整体放大（分组卡 12.5、节点 11）
- 可用条去掉文字图例，只显示「共 N 个」

**修复**
- 分段进度条色块不显示
- 代理页偶发「0 个分组」空白
- 实时流量 / 内存长时间不刷新
- 累计流量在连接流断开后停止更新

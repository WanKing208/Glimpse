# 更新日志

## v0.60.1

**新增**
- 规则列表显示目标代理组的配置 logo（`icon` 字段），DIRECT/REJECT 用图标占位
- 连接详情弹窗新增「原始数据」页（可复制 JSON）
- 连接分组新增「按时间」，按 `HH:mm` 分桶
- 设置 → 主题 → 节点卡：字号、上下间距、内部留白可调

**优化**
- 连接卡重排：左侧类型/域名/链路/规则，右侧流量与时间；连接时刻移至右下角
- 连接按建立时间倒序，新连接永远在最前
- 类型字段加粗提亮，与次要信息区分
- 切页动画改为弹性曲线（1.055 → 0.99 → 1.0），与底栏手感一致
- 分组延时角标放大至 14

**修复**
- 代理页偶发空白/红字：请求失败重试 3 次，仍失败保留上次数据
- 点击分组延时无反应：整组接口失败时退化为逐节点测速，并显示转圈
- 手动锁不消失：点测速即刻解锁，不再依赖测速成功
- 选中节点后分组延时不动：立即本地反映 + 清除该节点旧测速值
- 字段设置里关掉「连接时长」后仍显示
